마이페이지 API 테스트

MyPageController의 API들을 테스트합니다.

👤 마이페이지 기본 정보 조회

로그인한 회원의 기본 정보와 최근 작성 게시글을 조회합니다.

GET /api/members/mypage
📝 내 게시글 목록 (정렬/필터)

작성한 게시글을 정렬 및 태그로 필터링합니다.

GET /api/members/mypage/posts
🔖 내 북마크 목록 (정렬/필터)

북마크한 게시글을 정렬 및 태그로 필터링합니다.

GET /api/members/bookmark

GET /api/members/analytics
