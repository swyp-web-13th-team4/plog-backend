피드(Feed) API 테스트

게시글 목록 조회 및 북마크, 좋아요 기능 등을 테스트합니다.

📖 피드 전체 조회

최신 게시글 목록을 불러옵니다.

GET /api/feed/list
🔍 피드 상세 조회
GET /api/feed/{postId}
👤 다른 유저 프로필 조회

특정 유저의 프로필 정보 및 기본 데이터를 조회합니다.

GET /api/feed/profileView/{memberKey}
🗂️ 다른 유저 게시글 목록 조회

대상 유저의 게시글들을 정렬하여 불러옵니다.

GET /api/feed/profileView/{memberKey}/posts
⭐ 북마크 토글
POST /api/feed/bookmark/{postId}
❤️ 좋아요 토글
POST /api/feed/like/{postId}
← 로그인 성공 페이지 📝 게시글 작성(새창)
